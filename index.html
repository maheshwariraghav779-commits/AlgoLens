University Curriculum

Comprehensive Modules (1 to 7)

Click on any module below to jump directly into its interactive workbench with step-by-step animations and memory tracking.

📊 Module 1

Arrays, Searching & Sorting

O(n log n)

Covers 9 sorting algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap, Radix, Shell, Bucket), 4 search strategies (Linear, Binary, Indexed, Fibonacci), 2D Address Mapping, and Sparse Matrix Fast/Simple Transpose.

Sorting (9 algorithms) Fibonacci Search Row/Col Major Addr Sparse Transpose
🔗 Module 2

Linked Lists, DLL, CLL & GLL

O(1) / O(N)

Singly Linked List (SLL), Doubly Linked List (DLL with prev & next), Circular Linked List (CLL with tail-to-head loop), Generalized Linked List (GLL with atoms & sublists), In-place Reversal, and Vector Doubling.

SLL Insert/Delete DLL (prev ⇄ next) CLL (Tail ↺ Head) GLL (Atoms & Sublists) In-Place Reversal Vector Doubling
🥞 Module 3

Stacks, Queues & Deque

LIFO / FIFO

Expression conversions (Infix to Postfix, Infix to Prefix), Stack Postfix evaluation, Circular Queue with modulo wraparound, Double Ended Queue (Deque with front & rear access), and Josephus elimination.

Infix to Postfix Infix to Prefix Postfix Eval Circular Queue Deque (Front ⇄ Rear) Josephus Problem
🌳 Module 4

Trees & Binary Search Trees

O(H) = O(log N)

Binary Search Tree (BST) recursive insertion, 3-case deletion (leaf, single-child, two-children with in-order successor), and Threaded Binary Trees (TBT) with zero-stack pointer threading.

BST Insert BST Delete (3 Cases) Threaded Tree (TBT)
🕸️ Module 5

Graphs & Minimum Spanning Trees

O(E log V)

Greedy single-source shortest paths via Dijkstra's algorithm, Kruskal's Minimum Spanning Tree with Disjoint Set Union (find/union), and BFS 2-coloring bipartite cycle detection.

Dijkstra Shortest Path Kruskal's MST Bipartite 2-Coloring
🗝️ Module 6

Hashing & Collision Strategies

O(1) Average

Open addressing with Linear Probing (primary clustering analysis) and Quadratic Probing, closed addressing via Separate Chaining linked lists, and dynamic Extendible Hashing directory doubling.

Linear Probing Quadratic Probing Separate Chaining Extendible Hashing

UNIX File System & Directory Tree Explorer

Interactive real-world application of tree hierarchies in UNIX OS: SVG tree diagram synchronized with a collapsible sidebar explorer, DFS Pre/In/Post traversals, BFS level-order, pathfinding, and recursive post-order folder size aggregation.
